# Промосайт Find a Note

Для сборки и предпросмотра нужен Node.js 22 или новее. Из корня репозитория:

```powershell
node website/build.mjs
node website/preview.mjs
```

Откройте http://127.0.0.1:4173/find-a-note/. После правок повторите сборку и обновите страницу. Статический результат находится в `website/dist/`. Для GitHub Pages содержимое этого каталога должно стать корнем артефакта сайта. GitHub Pages добавляет префикс `/find-a-note/`, а ссылки на изображения и стили относительные.

## Проверка

```powershell
node website/build.mjs
node website/check.mjs
```

Проверка использует Microsoft Edge и Playwright из установленных зависимостей `frontend/`. Сборка и предпросмотр сайта не требуют этих зависимостей. Тест запускает собственный локальный сервер со свободным портом.

## Контент и загрузки

Русские тексты находятся в `content/ru.json`. Для английской версии добавьте `content/en.json` с теми же ключами и вызовите рендеринг того же шаблона для выходного файла `en/index.html`, скорректировав относительные ссылки на общие ресурсы для вложенного пути.

`content/release.json` содержит ссылки из публичного GitHub Release. При обновлении сверьте имена и URL через `https://api.github.com/repos/pembrock/find-a-note/releases/latest` и проверьте HTTP-доступность. Если URL отдельного файла нельзя подтвердить, удалите его поле. Сборка направит соответствующую ссылку на страницу последнего релиза.
