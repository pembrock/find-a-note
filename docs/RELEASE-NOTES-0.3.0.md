English

- Find a Note is now available in English and Russian. On first launch, the app uses Russian for a Russian system locale and English otherwise.
- Change the language in Settings → General → Language. Your choice is saved. You can switch during a training session, MIDI calibration, or an update dialog.
- Letter names, Do–Re–Mi note names, and octave names remain independently configurable. Update notes appear in the selected language when both translations are available.

Русский

- Find a Note доступен на русском и английском. При первом запуске приложение выбирает русский для русской локали системы и английский для остальных локалей.
- Язык можно изменить в разделе «Настройки → Общие → Язык приложения». Выбор сохраняется. Переключение доступно во время тренировки, калибровки MIDI и в диалоге обновления.
- Буквенные обозначения, названия нот до–ре–ми и названия октав по-прежнему настраиваются отдельно. Если заметки о выпуске переведены, приложение показывает их на выбранном языке.
