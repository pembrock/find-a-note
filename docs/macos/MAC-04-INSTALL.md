# Установка Find a Note на Mac

Эта сборка 0.3.0 предназначена для Mac с Apple Silicon (серии M).
Работа проверена на macOS 27.2.1.

1. Откройте `Find-a-Note-0.3.0-macOS-arm64.dmg` в Finder.
2. Перетащите **Find a Note.app** на ярлык **Applications**
   («Программы»).
3. Извлеките том **Find a Note** в боковой панели Finder.
4. Откройте **Find a Note** из папки «Программы».

Сборка использует локальную подпись ad hoc. У неё нет сертификата
Developer ID и нотариального заверения Apple. После загрузки macOS может
заблокировать запуск. Если вы доверяете источнику и сверили SHA-256 с суммой,
полученной от владельца проекта, после попытки открытия проверьте
**Системные настройки → Конфиденциальность и безопасность → Открыть всё равно**.
Кнопка доступна около часа после попытки запуска, если политика Mac разрешает
исключение. Если кнопки нет или система сообщает о вредоносном ПО, прекратите
установку. [Инструкция Apple](https://support.apple.com/guide/mac-help/mh40617/mac)

Чтобы обновиться вручную, завершите Find a Note через **⌘Q**, откройте новый
образ и замените приложение в «Программах». Чтобы удалить приложение, завершите
его и переместите **Find a Note** из «Программ» в Корзину. Настройки сохраняются
в профиле macOS, поэтому обычное удаление приложения оставляет их для повторной
установки.
