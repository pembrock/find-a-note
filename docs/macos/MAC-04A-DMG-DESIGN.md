# MAC-04A — оформление установочного DMG

Find a Note открывается в окне Finder 600 × 360 точек. Название приложения
стоит над двумя иконками, фиолетовая стрелка ведёт от Find a Note слева к
Applications справа. Под иконками — подсказка **Drag to Applications**.
Палитра повторяет тёмный интерфейс приложения, а музыкальный акцент задаёт
его собственная иконка. В окне скрыты боковая панель, панель инструментов,
строка состояния, панель пути и вкладки.

## Сборка

Требования к Go, Node, Wails и Xcode описаны в [MAC-04](MAC-04-DISTRIBUTION.md).
Для оформления нужны Python 3.9+ и бесплатный `dmgbuild`. Установка
закреплённых зависимостей в изолированное окружение из корня проекта:

```sh
mac_dmg_venv="$(mktemp -d)/venv"
python3 -m venv "$mac_dmg_venv"
"$mac_dmg_venv/bin/python" -m pip install -r build/darwin/dmg/requirements.txt
DMGBUILD_PYTHON="$mac_dmg_venv/bin/python" ./scripts/build-macos.sh
```

Путь к `python3` по умолчанию берётся из `PATH`. Сценарий сохраняет
артефакты в `artifacts/mac-04a/`. Для новой сборки используйте отдельный
каталог вывода, передав его первым аргументом. Swift и AppKit рисуют фон
600 × 360 и 1200 × 720 пикселей. `dmgbuild` объединяет их в один HiDPI TIFF и
создаёт HFS+ UDZO с `.DS_Store`, закладкой на фон и позициями иконок.
Сценарий монтирует финальный образ только для чтения, разбирает метаданные,
проверяет ровно два видимых объекта, сравнивает .app со staging и снова
проверяет её подпись. Оформление создаётся внутри временного тома.
[Настройки dmgbuild](https://dmgbuild.readthedocs.io/en/stable/settings/)

## Установка

Откройте DMG, перетащите иконку по стрелке на Applications, извлеките том и
запустите приложение из «Программ». Для замены завершите текущую копию
через ⌘Q. Обычное удаление приложения через Finder сохраняет профиль
WKWebView. [Инструкция для пользователя](MAC-04-INSTALL.md)

## Gatekeeper

Приложение подписано ad hoc. Для проверки сценария загрузки скачайте DMG
браузером на тестовом Mac с активной защитой и сравните SHA-256. Откройте DMG,
скопируйте приложение через Finder и проверьте quarantine на обоих путях:

```sh
xattr -p com.apple.quarantine "$HOME/Downloads/Find-a-Note-0.3.0-macOS-arm64.dmg"
xattr -p com.apple.quarantine "/Applications/Find a Note.app"
spctl --assess --type execute --verbose=4 "/Applications/Find a Note.app"
```

Откройте приложение из Applications. Если macOS блокирует запуск, зафиксируйте
текст предупреждения и проверьте наличие «Открыть всё равно» в «Системных
настройках → Конфиденциальность и безопасность». Допустимость исключения
зависит от настроек компьютера и решения пользователя.
[Справка Apple](https://support.apple.com/ru-ru/102445)

## Проверка 20 ноября 2026

Mac с Apple Silicon, macOS 27.2.1 (26B131), Finder в тёмном режиме на Retina,
Chrome 148.0.7778.168. Артефакты и журналы находятся в `artifacts/mac-04a/`.

| Проверка | Результат |
| --- | --- |
| Визуальный макет | **PASS**. Реальный Finder открыл окно 600 × 360 точек. Видны две подписанные иконки, фон, стрелка, заголовок и подсказка. Первый вариант показал чёрные подписи на тёмном фоне. Светлые подложки восстановили читаемость. Финальный снимок `screenshots/finder-dmg.jpg` имеет 1200 × 720 пикселей. |
| Метаданные и состав | **PASS**. Finder использовал `.DS_Store` внутри DMG. HiDPI TIFF содержит 600 × 360 и 1200 × 720. На томе два видимых объекта. Сборка и проверка проходят на отдельном томе. |
| Установка и замена | **PASS** через копирование Finder с открытием ярлыка Applications, затем подтверждением «Заменить» для одноимённого bundle версии 0.3.0. Автоматизированное перетаскивание выделяло иконку, но не создавало копию. Успешное ручное перетаскивание этого образа **NOT TESTED**. |
| Запуск и удаление | **PASS**. Локальная установленная .app запустилась дважды после извлечения DMG. Тестовая копия удалена из Applications через Корзину и прежний bundle возвращён. | Production и регрессии | **PASS**. Frontend build, unit-тесты 13/13, Go test/vet и embedded test. Info.plist, Mach-O arm64, codesign, ресурсы, лицензии и SHA-256 проверены. .app совпадает с MAC-04 побайтово. |
