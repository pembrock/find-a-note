# MAC-02 · CoreMIDI

База — MAC-01, `9ee39f489f27e7c2ae18bf7cae029ebe6afe3161`.
Проверено на Apple Silicon, macOS 27.2.1 (26B131), SDK 27.2, Wails 2.17.0.
Deployment target приложения — 11.0. Старые версии macOS не проверялись.

`internal/midi/driver_darwin.go` и `coremidi_darwin.c` реализуют
Darwin+cgo драйвер. Клиент CoreMIDI живёт до остановки менеджера и создаётся
на закреплённом системном потоке. Перед перечислением источников менеджер
даёт CFRunLoop обработать системные события. Это требуется для обновления
представления CoreMIDI при изменении состава источников. Сам менеджер
по-прежнему владеет опросом, подключением и переподключением.

`MIDIInputPortCreateWithProtocol` запрашивает MIDI 1.0 и доступен с macOS
11.0. Вызов защищён проверкой доступности, поскольку Wails передаёт Clang
target 10.13 при сборке C. Пакеты обходятся через `MIDIEventPacketNext` и
длину UMP по типу. Системный итератор UMP требует 12.0. Передаются Note
On/Off и CC120/123 с исходными каналами и velocity. Менеджер преобразует
Note On с velocity 0 в Note Off и сбрасывает удержания при смене сессии.

Перечисление использует `MIDIGetNumberOfSources`, `MIDIGetSource` и
свойства CoreMIDI. Известные offline-источники скрыты. Имя берётся из
DisplayName. Идентификатор текущего подключения содержит handle и
постоянную часть `coremidi:<unique-id>`. Для отсутствующего ID разрешён
ручной выбор, а профиль диапазона и звук ограничены сессией. При
неоднозначном совпадении действуют существующие правила менеджера и UI.
Объект CFString освобождается после копирования имени.

Receive block захватывает только числовой токен. Go хранит приёмник
отдельно. Закрытие удаляет токен и ждёт текущий короткий вызов очереди,
затем отсоединяет источник и освобождает порт. Поздний callback не получает
доступа к закрытому приёмнику. При завершении менеджер освобождает клиент,
а Shutdown ждёт завершения этой операции.

`app.go` передаёт драйвер по указателю, `manager.go` закрывает драйверы с
собственным lifecycle. `driver_other.go` остаётся заглушкой вне Windows и
Darwin+cgo. WinMM использует прежние файлы. Изменения `useMidi.ts`,
`useCalibration.ts` и `useAudio.tsx` учитывают пустой ID, сохраняя формат
событий и ключи storage. Алгоритмы тренировок и Tone.js прежние.
`driver_darwin_test.go` и `testdata/source.c` проверяют UMP и CoreMIDI.

Автоматическую проверку с виртуальным источником запускать из корня:

```sh
mkdir -p artifacts/mac-02
clang -framework CoreMIDI -framework CoreFoundation \
  internal/midi/testdata/source.c -o artifacts/mac-02/source
FIND_A_NOTE_MIDI_FIXTURE="$PWD/artifacts/mac-02/source" go test -count=1 -v ./internal/midi
```

Для проверки на Yamaha P-45 выбрать устройство в меню ввода, отключить
транспонирование и в мастере нажать крайние клавиши. Ожидаемый диапазон
A0–C8 (21–108). Для SE25 сначала записать octave shift и сравнить диапазон
с крайними физическими клавишами. Для обоих сыграть аккорд, отпустить
клавиши по одной, проверить быстрый повтор и вынуть кабель при удержании.
Подключить обратно, затем перезапустить приложение и проверить выбранный
порт и границы. Повторить на другом USB-порту для проверки постоянного ID.
С включённым звуком проверить выключение удерживаемых нот, смену входа и
переключение языка при удержании.

Для MAC-03 проверить Web Audio внутри WKWebView с реальным выводом звука,
включая unlock, аккорды, blur, sleep/wake и запуск без сети. Отдельно
проверить профиль при переносе bundle и на чистой установке.
