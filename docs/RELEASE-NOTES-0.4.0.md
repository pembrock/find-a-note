English

- First macOS release for Apple Silicon, with a drag-to-Applications DMG and CoreMIDI for physical MIDI keyboards.
- The interface is available in English and Russian on Windows and macOS.
- Windows keeps its existing signed update flow for Installer and Portable. On macOS, the app verifies the available DMG and shows its checksum before directing you to the official release for manual installation.
- The macOS build uses ad hoc signing. Gatekeeper may block the first launch after download. This release targets Apple Silicon; Intel Macs are outside its scope. macOS validation covered 27.2.1.

Русский

- Первый выпуск для Mac на Apple Silicon. Установка перетаскиванием из DMG, подключение MIDI-клавиатур через CoreMIDI.
- Русский и английский интерфейсы доступны на Windows и macOS.
- Windows сохраняет проверяемое обновление Installer и Portable с подтверждением установки. На macOS приложение проверяет доступный DMG и показывает контрольную сумму, затем предлагает открыть официальный релиз для ручной установки.
- Сборка macOS подписана ad hoc. Gatekeeper может заблокировать первый запуск после скачивания. Выпуск предназначен для Apple Silicon. Проверки macOS выполнены на 27.2.1.
