# MIDI-02: калибровка диапазона инструмента

В нижней панели выберите физический MIDI-вход. Для нового устройства Find a Note один раз предлагает калибровку. Кнопка «Позже» закрывает предложение. Чтобы вернуться к калибровке, выберите «Устройство ввода» → «Определить диапазон» или «Определить заново».

1. Отключите транспонирование и смещение октавы на инструменте. Нажмите «Начать».
2. Нажмите крайнюю левую клавишу, затем крайнюю правую. Используются реальные MIDI Note On с velocity > 0, из того же порта MIDI-01. Виртуальные клики не захватывают границы.
3. Проверьте ноты, MIDI-номера и число высот непрерывного хроматического диапазона. Для стандартной Yamaha P-45 ожидается A0–C8 / MIDI 21–108 / 88 нот, но программа не подставляет эти значения.
4. Нажмите «Сохранить». Только это действие заменяет подтверждённые границы. «Отмена» и ошибка сохранения сохраняют прежний профиль.

Мастер блокирует передачу своих нажатий в тренировку; существующая обратная связь приостанавливается до закрытия мастера. Note Off и velocity 0 не захватывают границы. Повторные Note On удерживаемой ноты подавляет существующий MIDI-01 backend. При разрыве/смене MIDI-сессии незавершённые границы отбрасываются; после восстановления нужно нажать «Определить заново». Автопереподключение MIDI-01 продолжает работать.

Подтверждённые данные хранятся отдельно в `sonari.midi.calibration.v1`: версия, массив профилей (WinMM identity, имя, lowerMidiNote, upperMidiNote, confirmed), а также список уже предложенных настроек. Используется та же идентичность WinMM capabilities, что в MIDI-01. Если несколько входов имеют одинаковую идентичность, сохранённый профиль не применяется автоматически. Явно подтверждённый диапазон используется только в текущей сессии, без перезаписи долговременных профилей; интерфейс сообщает это ограничение.

«Вся клавиатура» генерирует ноты в подтверждённых границах. Выбранные, включая несмежные, октавы пересекаются с инструментом. Недоступные октавы скрыты, частичные показывают фактические границы. Исходные настройки не меняются при подключении или калибровке. Если пересечение пустое, задания блокируются и предлагается явное действие «Использовать доступный диапазон» либо «Виртуальный ввод».

«Первые ноты» остаются неизменными наборами 5/7: если хотя бы одна нота недоступна, режим сообщает об этом и не выдаёт частичный набор. Предложение доступного диапазона переводит в свою тренировку только после нажатия пользователем.

Виртуальный ввод возвращает A0–C8 и прежние настройки, не удаляя физические профили. Визуальное пианино не сужается до физической калибровки; для MIDI-диапазонов вне A0–C8 его отображение расширяется, чтобы текущая нота 0–127 оставалась видима. Выбор виртуального ввода снова ограничивает инструмент A0–C8.

Калибровка измеряет передаваемые MIDI-высоты двух клавиш. Она не проверяет остальные клавиши и не определяет модель, серийный номер или физическое количество клавиш. Изменение transpose/octave shift требует повторного определения. Ограничения обнаружения USB и идентификации WinMM сохраняются из [MIDI-01](MIDI-01.md).

## Аппаратная проверка

Yamaha P-45 (`Digital Piano`) проверена реальными MIDI-нажатиями. Пользователь нажал левую границу A0 (MIDI 21), затем правую C8 (MIDI 108). Мастер показал 88 высот хроматического диапазона. Во время обеих калибровочных нот прогресс остался 0, число ошибок — 14. Пользователь нажал «Сохранить»; меню устройства показывает A0–C8 / MIDI 21–108. Проверены реальные окна 900×600, 760×560 и развёрнутое 1920×1032; компактный результат полностью помещается.

SE25 присутствовал в списке, но по просьбе пользователя аппаратная проверка завершена на Yamaha. Раздельные профили, неоднозначные идентичности, отключение в мастере и восстановление проверены автоматическими сценариями с тестовыми MIDI-событиями. Реальное извлечение USB во время мастера не выполнялось. Ограничения Windows 10, других DPI и WinMM остаются в силе.
