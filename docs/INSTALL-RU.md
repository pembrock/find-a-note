# Установка Find a Note

Скачивайте файлы со страницы [официальных выпусков](https://github.com/pembrock/find-a-note/releases).
Перед запуском сравните SHA-256 скачанного пакета с `SHA256SUMS.txt` выпуска.

## Windows 10 и 11, x64

Запустите файл `*-Windows-Setup.exe` для установки в профиль текущего
пользователя либо сразу запустите `*-Windows-Portable.exe`. Если Microsoft
Edge WebView2 Runtime отсутствует, приложение или установщик предложит
установить его. Для загрузки Runtime понадобится интернет.

Меню **Настройки → О программе → Проверить обновления** позволяет скачать
и проверить подходящее обновление. Установка начинается после подтверждения.

## macOS на Apple Silicon

1. Откройте `Find-a-Note-<версия>-macOS-arm64.dmg`.
2. Перетащите **Find a Note** по стрелке на **Applications**.
3. Извлеките том и откройте приложение из папки «Программы».

Сборка подписана ad hoc и распространяется без нотарификации Apple. Если
Gatekeeper блокирует запуск новой копии, проверьте источник и SHA-256 DMG.
Попробуйте открыть установленное приложение, затем выберите **Системные
настройки → Конфиденциальность и безопасность → Всё равно открыть**, если
действие доступно по политике вашего Mac. В следующем диалоге подтвердите
**Открыть**. [Инструкция Apple](https://support.apple.com/ru-ru/102445)

### Обновления macOS

- **С 0.4.0 на 0.4.1.** Скачайте arm64 DMG версии 0.4.1 из официального
  выпуска и сверьте SHA-256. Завершите Find a Note через ⌘Q, замените приложение
  в папке «Программы» через DMG и откройте новую копию.
- **После установки 0.4.1.** Выберите **Настройки → О программе → Проверить
  обновления**. В поддерживаемом каталоге с правом записи приложение загрузит
  и проверит новый выпуск. Подтвердите установку и перезапуск. Gatekeeper
  может потребовать разрешение на запуск новой копии.
- **Ручной вариант.** Если приложение запущено с DMG или установлено в
  неподдерживаемом каталоге, диалог предложит проверенный DMG. Скачайте его
  из официального выпуска, сверьте SHA-256 с показанным в диалоге,
  завершите приложение и замените его вручную.
- **Восстановление.** Если новая копия не запускается после обновления,
  используйте кнопку **Восстановить** в диалоге помощника обновления.
