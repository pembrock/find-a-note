# Установка Find a Note

Скачивайте файлы со страницы [официальных выпусков](https://github.com/pembrock/find-a-note/releases).
Перед запуском сравните SHA-256 скачанного пакета с `SHA256SUMS.txt` выпуска.

## Windows 10 и 11, x64

Запустите файл `*-Windows-Setup.exe` для установки в профиль текущего
пользователя либо сразу запустите `*-Windows-Portable.exe`. Если Microsoft
Edge WebView2 Runtime отсутствует, приложение или установщик предложит
установить его. Для загрузки Runtime понадобится интернет.

Меню **Настройки → О программе → Проверить обновления** позволяет скачать
и проверить подходящее обновление. Установка начинается после подтверждения.

## macOS на Apple Silicon

1. Откройте `Find-a-Note-0.4.0-macOS-arm64.dmg`.
2. Перетащите **Find a Note** по стрелке на **Applications**.
3. Извлеките том и откройте приложение из папки «Программы».

Сборка подписана ad hoc. Если macOS блокирует первый запуск, после проверки
источника и SHA-256 откройте **Системные настройки → Конфиденциальность и
безопасность → Всё равно открыть**. Доступность действия зависит от настроек
Mac. [Инструкция Apple](https://support.apple.com/ru-ru/102445)

Для обновления проверьте новый DMG в диалоге обновлений. Затем скачайте его
через браузер, сравните SHA-256 с указанным в диалоге, завершите Find a Note
через ⌘Q и замените приложение в папке «Программы».
