# I18N-01 · Русский и английский интерфейс

## Выбор языка

При запуске React читает `sonari.language.v1` из localStorage профиля WebView2.
Явный выбор `ru` или `en` имеет приоритет. При отсутствии выбора используется
`navigator.language`. Основной подтег `ru` выбирает русский, остальные локали
выбирают английский. Автоматический результат остаётся в памяти, поэтому при
следующем запуске приложение снова учитывает язык среды. Локаль обрабатывается
на устройстве.

Ручной выбор доступен в «Настройки → Общие → Язык приложения», в мастере
калибровки и в диалоге обновления. React меняет тексты и атрибут `lang` без
перемонтирования приложения. Сохраняются текущее упражнение, счёт, MIDI-сессия,
захваченная граница калибровки и настройки звука. У этих настроек прежние ключи
и форматы хранения. При недоступном localStorage выбор применяется до выхода,
а рядом с полем появляется сообщение об ошибке сохранения.

## Словари и ошибки

Переводы хранятся в `frontend/src/locales/ru.json` и
`frontend/src/locales/en.json`. Контекст в `frontend/src/i18n.tsx` отдаёт
типизированную функцию `t` и использует штатные средства React. Добавляйте
ключ в оба словаря. Динамические
значения задавайте именованными параметрами вроде `{version}`. Прогон
`npm test` проверяет совпадение, заполненность и использование ключей, а также
интерполяцию. MIDI-имена, версии, название приложения и имена авторов выводятся
как получены.

Буквенное обозначение, названия до–ре–ми и названия октав по-прежнему управляются
своими настройками. В английском интерфейсе используются Do–Re–Mi и номер
октавы в научной нотации, в русском — русские названия. MIDI-сопоставление,
правила упражнений и аудиодвижок используют прежние данные.

Go-менеджер MIDI отправляет стабильные коды через поле `message`. React
отображает их на выбранном языке. Детали ошибок драйвера доступны в
диагностическом выводе. Updater использует прежние коды фаз и ошибок. Для
аварийного нативного окна helper язык берётся из Windows UI locale, поскольку
WebView2 может быть недоступен.

## Подписанные заметки о выпуске

Используйте [двуязычный файл заметок](RELEASE-NOTES-0.3.0.md) для GitHub Release
и параметра `-UpdateNotes` существующего сборочного сценария. Формат текста
состоит из строки `English`, пустой строки, английского текста, пустой строки,
строки `Русский`, пустой строки и русского текста. Соблюдайте действующее
ограничение в 4096 байт UTF‑8.

Обе секции хранятся в существующем строковом поле `notes` манифеста схемы 1.
Старая версия 0.2.2 отображает обе секции как обычный текст. Версия 0.3.0
выбирает нужную секцию уже после успешной проверки подписи. Старые одноязычные
заметки и тексты без двух полных секций отображаются целиком. Канонизация,
проверка Ed25519 и сверка размера и SHA‑256 пакетов используют существующий
протокол. Процедура подписания описана в [UPDATE-01](UPDATE-01.md).
