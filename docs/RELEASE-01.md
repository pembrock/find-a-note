# RELEASE-01 · Find a Note 0.1.0

## Структура и платформы

- `main.go`, `app.go` и `version.go` запускают Wails и связывают окно с Go.
- `internal/midi` содержит общий менеджер MIDI. WinMM изолирован в `driver_windows.go` по тегу `windows`. Неплатформенный драйвер позволяет собирать общий пакет. Будущий CoreMIDI подключится через существующий интерфейс `Driver`.
- `frontend/src` содержит общий интерфейс React, упражнения, VexFlow и аудиодвижок Tone.js. Wails встраивает `frontend/dist`, включая сэмплы из `frontend/public/audio`.
- `build/windows` содержит Windows-ресурсы и сценарий NSIS. Сборка RELEASE-01 предназначена для Windows 10/11 x64.

## Сборка Windows

В Windows нужны Go 1.25+, Node.js 22+, Wails CLI 2.17.0 и NSIS 3.x с `makensis.exe` в PATH. Проверенная версия NSIS — 3.12. Wails CLI устанавливается командой `go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0`.

```powershell
./scripts/build-release.ps1
```

Сценарий выполняет `npm ci`, сборку TypeScript и Vite, собирает уведомления о лицензиях и запускает Wails в production-режиме с `-trimpath` и `-nsis -installscope user`. Результаты лежат в `artifacts/windows-0.1.0/`. Исходный EXE находится в `build/bin/Find a Note.exe`. Portable — тот же EXE под именем релизного артефакта. Для воспроизведения сборки используйте чистую копию выбранного коммита и те же версии инструментов.

Установщик по умолчанию размещает приложение в `%LOCALAPPDATA%\Programs\Find a Note`, создаёт ярлык в меню «Пуск» и запись в списке установленных приложений текущего пользователя. Ярлык рабочего стола выбирается на странице компонентов. Перед повторной установкой закройте приложение. Для автоматизированного запуска доступны ключи NSIS `/S` у установщика и деинсталлятора.

Установщик проверяет WebView2 Runtime и при необходимости запускает загрузчик Microsoft. В EXE встроен тот же загрузчик через Wails, поэтому при отсутствии подходящего Runtime Portable предлагает его установить. Загрузчику нужен интернет. После установки Runtime тренировки и аудио работают локально. Windows-артефакты выпускаются без подписи.

## Версия и GitHub Releases

Единственный источник версии приложения — `info.productVersion` в `wails.json`. Go читает встроенную конфигурацию. React использует тот же JSON в разделе «О программе». Wails подставляет значение в ресурсы PE и NSIS, а сценарий использует его при именовании артефактов. В репозитории Go сохраняет доступные сведения VCS в build info, которую можно прочитать командой `go version -m`. Для разработки используется `wails dev`. В дальнейшем механизм обновлений сможет использовать числовую версию приложения и тег `vX.Y.Z`.

Порядок ручной публикации после отдельного согласования.

1. Измените `info.productVersion` на следующую версию, выполните проверки и зафиксируйте изменения в Git.
2. Соберите Windows-файлы из чистого коммита. Сверьте версии в EXE и в «О программе», проверьте оба способа запуска и повторную установку с сохранением настроек.
3. Для публичного репозитория `find-a-note` создайте релиз с тегом `vX.Y.Z` на проверенном коммите. Для версии 0.1.0 тег будет `v0.1.0`. Прикрепите три файла из соответствующего каталога сборки.

   - `Find-a-Note-0.1.0-Windows-Setup.exe`
   - `Find-a-Note-0.1.0-Windows-Portable.exe`
   - `SHA256SUMS.txt`

4. Сверьте скачанные файлы по SHA-256. Для будущего macOS-релиза предусмотрены имена `Find-a-Note-X.Y.Z-macOS-arm64.dmg` и `Find-a-Note-X.Y.Z-macOS-amd64.dmg`.

## Настройки и совместимость

Sonari и оба варианта Find a Note используют один профиль `%APPDATA%\Sonari.exe` и origin `http://wails.localhost/`. Сохранены ключи `sonari.*` для интерфейса, тренировок, звука, MIDI-входа и калибровок. Переименование EXE обходится без переноса данных. Деинсталлятор удаляет EXE, ярлыки и регистрационную запись приложения. Профиль остаётся доступен для Portable, повторной установки и Sonari. Закрывайте одну версию перед открытием другой при работе с общим профилем.
