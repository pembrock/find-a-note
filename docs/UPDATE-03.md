# UPDATE-03 · Find a Note 0.2.1

## Звук и совместимость

Для нового физического MIDI-устройства звук включён по умолчанию. Существующее значение источника из `sonari.audio.v1` имеет приоритет, включая явное `false`. Формат хранилища не изменился. Виртуальная клавиатура сохраняет отдельную настройку.

В меню «Устройство ввода» для подключённого MIDI-источника доступен переключатель «Воспроизводить звук». Он использует то же состояние, что и «Настройки → Звук». При выборе устройства мышью или клавиатурой приложение запрашивает активацию Web Audio. WinMM, Tone.js, маршрутизация MIDI-событий, упражнения и калибровка не менялись.

У устройств со встроенным звуком можно выключить программное воспроизведение. Если два входа имеют одинаковую идентичность, настройка такого входа действует в текущем сеансе по прежним правилам. WebView2 может потребовать жест для запуска звука после автоматического подключения.

## Ручная проверка SE25

Из корня отдельного worktree запустите Portable с пустым тестовым профилем в PowerShell 7:

```powershell
$exe = (Resolve-Path ./artifacts/windows-0.2.1/Find-a-Note-0.2.1-Windows-Portable.exe).Path
$profile = (New-Item -ItemType Directory (Join-Path $env:TEMP ('Find-a-Note-0.2.1-' + [guid]::NewGuid()))).FullName
Start-Process -FilePath $exe -Environment @{ APPDATA = $profile }
```

Выберите SE25. Если откроется калибровка, завершите или отложите её. Проверьте звук отдельных нот, удержания и аккордов. Выключите звук в меню устройства и проверьте положение переключателя в «Настройки → Звук». Закройте Portable. Для повторного запуска выполните только последнюю команду с тем же `$profile`. Убедитесь, что выключенное состояние сохранилось после перезапуска и повторного подключения USB. Сообщите итоги ручной проверки до публикации. [English release notes](RELEASE-NOTES-0.2.1.md).
