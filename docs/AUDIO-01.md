# AUDIO-01 — встроенное акустическое фортепиано

## Реализация

Tone.js 15.1.22 / Web Audio API, `AudioService` в `frontend/src/audio.ts`.
Один AudioContext (`latencyHint: interactive`, `lookAhead: 0`), предварительное
декодирование 30 локальных MP3. Note On не ждёт проверки ответа или React render.
Ошибочные ноты, аккорды и нажатия во время обратной связи тоже воспроизводятся.
Note Off освобождает соответствующую ноту с плавным затуханием 0,65 с.
Запись фортепиано естественно затухает при удержании; искусственного зацикливания нет.
Поддерживаемый звуковой диапазон A0–C8. Музыкальная модель не изменена.

Поток WinMM → Wails `midi:note` сохранён; frontend теперь принимает Note Off.
Velocity 1–127 преобразуется в амплитуду плавной кривой. Калибровка беззвучна.
WinMM CC120/CC123 публикуют отпускание удерживаемых нот своего канала.
Повторные Note On удерживаемой MIDI-клавиши по-прежнему фильтрует backend.
Каналы и указатели учитываются отдельно; одинаковая высота остаётся звучать,
пока её удерживает хотя бы один источник. При последнем отпускании освобождаются
все голоса этой высоты. Разные высоты освобождаются независимо.

Смена MIDI-сессии, отключение, ошибка соединения, выключение звука, открытие
калибровки и потеря фокуса освобождают ноты. Виртуальные клавиши используют
pointer down/up/leave/cancel, также доступны Enter/Space. При скрытии клавиатуры
её ноты освобождаются. `pagehide`/размонтирование освобождают ресурсы.
Ошибка аудио не отключает тренажёр. Autoplay требует кнопки «Включить звук»
при приостановленном контексте; до загрузки банка готовность не показывается.

## Настройки

В существующей панели: «Воспроизводить звук», общая громкость 0–100%.
Громкость плавно меняет gain без изменения системной громкости Windows.
Настройки сохраняются в `sonari.audio.v1`.
Виртуальный ввод по умолчанию звучит. Для любого физического инструмента
первое включение явное: WinMM не сообщает, есть ли собственный звуковой движок.
Поэтому SE25 также нужно один раз включить вручную. Название модели не используется
для предположения об отсутствии встроенного звука. Yamaha P-45 автоматически
не дублируется. Выбор сохраняется по полной WinMM identity (manufacturer, product,
version, name). При одинаковой identity используется только текущая сессия;
настройка не переносится на неоднозначное устройство после переподключения.
Ограничение WinMM: физически разные приборы с одинаковой identity, подключаемые
по очереди, отличить невозможно; это ограничение также относится к калибровке.

## Сэмплы и лицензия

Salamander Grand Piano, акустический рояль Yamaha C5, автор Alexander Holm.
Источник: https://github.com/Tonejs/audio/tree/master/salamander
Лицензия этой конкретной поставки: CC BY 3.0 Unported,
https://creativecommons.org/licenses/by/3.0/ .
Разрешено включение и распространение с указанием авторства и лицензии.
Оригинальный README и полный текст лицензии включены в локальную поставку.
Атрибуция также показана в настройках приложения.

30 MP3, 2 012 677 байт аудиоданных (около 1,92 МиБ), без изменений файлов.
Это компактная однослойная MP3-выборка Tone.js, а не полный набор с 16 слоями.
Промежуточные ноты используют ближайший сэмпл (шаг исходных записей — малая терция).
Velocity регулирует громкость, динамические слои отсутствуют в данной выборке.
Файлы, атрибуция, лицензия, upstream README и SHA-256 находятся в
`frontend/public/audio/salamander/`. При сборке Wails они встраиваются в EXE.
Во время работы используются только адреса `/audio/salamander/*.mp3`, внешних
запросов за аудио нет. Tone.js — MIT, уведомление включено в `public/audio`.

## Итоговая проверка

Результаты автоматических и ручных проверок фиксируются в `VALIDATION.md`.
Браузерная проверка запрещает внешние запросы уже при первом запуске и декодировании;
это проверка автономности ресурсов, а не физическое отключение сети Windows.
Повторный запуск `npm run test:ui -- tests/audio.spec.ts` из `frontend`:
все 5 аудиотестов прошли, включая два ранее исправленных сценария.
Изменения реализации при финализации не потребовались.
Финальные `npm run build` и Windows-сборка Wails `build -s -skipbindings`
выполнены успешно последовательно. Итоговый файл: `build/bin/Sonari.exe`.
Лицензия, атрибуция и SHA-256 всех 30 исходных MP3 проверены и сохранены.

Пользователь подтвердил реальную проверку SE25: качество звука хорошее,
звучание воспринимается как натуральное, удержание клавиш и одновременное
воспроизведение аккордов работают. Общее впечатление положительное.
Небольшая задержка ощущается, но практически не мешает игре.
Точная задержка инструментально не измерялась; числовые оценки не заявляются.
Оптимизация задержки на этом этапе не выполнялась.

Отдельная аппаратная проверка отключения USB во время удержания, изменения
громкости, влияния velocity и Yamaha P-45 пользователем не подтверждена.
Их автоматические проверки не считаются аппаратной проверкой.

Дополнительный ручной чек-лист (не перечень подтверждённых результатов):
1. Запустить `build/bin/Find a Note.exe` или Windows Portable EXE, подключить SE25, завершить или пропустить калибровку.
2. В настройках включить звук для SE25; при необходимости нажать «Включить звук».
3. Проверить короткие и длинные ноты, C4+E4+G4, отдельное отпускание E4,
   слабые/сильные нажатия, повтор ноты, звучание неверного ответа и удержание верного.
4. Проверить громкость 0/25/100%, выключение звука при удержании, смену устройства.
5. Удерживая аккорд, отключить USB; проверить завершение звука и переподключение.
6. Открыть калибровку: её нажатия должны быть беззвучными.
7. Перезапустить EXE без интернета: проверить звуки и сохранение настроек.
8. Если доступна P-45, проверить, что Find a Note не звучит до явного включения.
9. Сообщить субъективную задержку и любые зависшие ноты; измерения отдельно.
