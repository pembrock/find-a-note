# Find a Note 0.4.2

## English

- The on-screen piano now highlights all keys held on a connected MIDI keyboard, including chords. Each key stays highlighted until released. The highlights clear when you disconnect or switch MIDI devices.
- Windows requires Windows 10 or 11 (x64) with Microsoft Edge WebView2 Runtime. The macOS build requires Apple Silicon (arm64). On macOS 0.4.1, you can install this update from **Settings → About → Check for updates** if the app is in a supported writable location.

[Corresponding source](https://github.com/pembrock/find-a-note/tree/v0.4.2)

## Русский

- Экранное пианино подсвечивает все удерживаемые клавиши подключённой MIDI-клавиатуры, в том числе при игре аккордов. Подсветка каждой клавиши гаснет при её отпускании. При отключении или смене MIDI-устройства подсветка сбрасывается.
- Для Windows нужны Windows 10 или 11 (x64) и Microsoft Edge WebView2 Runtime. Для macOS нужен Mac с Apple Silicon (arm64). В версии 0.4.1 для macOS обновление можно установить через **Настройки → О программе → Проверить обновления**, если приложение находится в поддерживаемом каталоге с правом записи.

[Исходный код выпуска](https://github.com/pembrock/find-a-note/tree/v0.4.2)
